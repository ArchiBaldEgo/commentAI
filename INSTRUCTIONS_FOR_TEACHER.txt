commentAI — памятка преподавателю (Python НЕ нужен)

1) Откройте папку commentAI-demo.
2) Запустите commentAI-test.exe.
   - Если Windows SmartScreen спросит: «Подробнее» → «Выполнить в любом случае».
3) Откроется браузер со страницей:
   http://127.0.0.1:9000/
   Если браузер не открылся автоматически — откройте этот адрес вручную.

Что доказывает, что модель реально работает:
- На странице есть блок «Текущая версия модели (production)». Это версия текущей модели.
- При вводе комментария показываются вероятности по классам (neg/neu/pos).
- Показывается «Предсказание модели».

Обучение модель меняется:
Модель обучается сама, но для этого нужно очень много примеров ()
1) Введите комментарий.
2) В выпадающем списке «Разметка для дообучения» выберите правильную метку (pos/neu/neg), если хотите «исправить» модель.
3) Нажмите «Отправить».
   - Количество примеров в feedback_buffer.jsonl увеличится.
4) Нажмите кнопку «Переобучить модель сейчас (retrain)».
5) Через несколько секунд обновите страницу (F5) и проверьте:
   - «Текущая версия модели (production)» должна измениться на новую;
   - блок «Последний retrain» должен быть success.

Где лежат данные (для проверки на диске):
- data/feedback_buffer.jsonl — накопленные примеры для обучения
- data/retrain_status.json — статус последнего переобучения
- models/production/VERSION — версия текущей модели

Как завершить работу:
- Закройте консольное окно, которое открылось вместе с приложением
  (или нажмите в нём Ctrl + C).
